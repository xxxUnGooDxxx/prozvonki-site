Запись разговоров через Shizuku

ProZvonki умеет автоматически записывать телефонные разговоры на Android 11 и новее — без root — с помощью приложения Shizuku. Записи сохраняются на телефоне в зашифрованном виде и привязываются к звонкам в журнале. Ниже — пошаговая настройка и важные оговорки.

Важно перед началом

  • Установите актуальную версию ProZvonki. Запись разговоров доступна в версиях приложения из Google Play и RuStore.
  • Shizuku — не наше приложение. Shizuku разрабатывает сторонняя команда RikkaApps. Мы не являемся авторами Shizuku и не несём ответственности за его работу. Скачивайте Shizuku только с официальной страницы релизов и используйте на свой риск.
  • Требуется Android 11 или новее. На более старых версиях запись через Shizuku недоступна.

Видеоинструкция

Как включить запись разговоров через Shizuku

Короткое видео показывает весь путь настройки: запуск Shizuku, выдачу разрешения в ProZvonki и включение авто-записи звонков.

Шаг 1. Установите ProZvonki

Установите актуальную версию ProZvonki из Google Play или RuStore — запись разговоров через Shizuku доступна в обеих версиях. Ссылки на магазины — на главной.

Шаг 2. Установите приложение Shizuku

Скачайте и установите Shizuku — отдельное приложение, которое даёт другим приложениям расширенные права без root. Берите его с официальной страницы релизов: github.com/RikkaApps/Shizuku/releases (пакет moe.shizuku.privileged.api). Shizuku также есть в некоторых магазинах приложений — устанавливайте только из проверенного источника.

Шаг 3. Запустите службу Shizuku

Сама по себе установка Shizuku ещё не включает его — нужно запустить службу. Это официальный процесс от разработчика Shizuku. Выберите подходящий способ.

Способ A — беспроводная отладка (Android 11+, без компьютера) — рекомендуется

  1. Включите параметры разработчика: Настройки → «О телефоне» и 7 раз нажмите на «Номер сборки», пока не появится «Вы стали разработчиком». На некоторых прошивках номер сборки находится в подразделе «Сведения о ПО» или «Версия».
  2. Откройте «Для разработчиков», включите «Отладка по USB», затем найдите и включите «Беспроводная отладка» (Wireless debugging).
  3. В приложении Shizuku нажмите запуск через беспроводную отладку — Shizuku предложит выполнить сопряжение.
  4. В настройках телефона откройте «Беспроводная отладка → Подключение устройства с помощью кода» и введите код сопряжения, который Shizuku показывает в своём уведомлении (делается один раз).
  5. Вернитесь в Shizuku и завершите запуск. Если не удаётся — выключите и снова включите беспроводную отладку. Если Shizuku пишет «Поиск службы сопряжения», разрешите приложению работу в фоне.

Способ B — через компьютер (ADB)

Подходит для Android 10 и старше или если беспроводная отладка недоступна. Скачайте SDK Platform Tools от Google, включите на телефоне «Отладка по USB», подключите его к ПК по USB и подтвердите разрешение отладки. Затем выполните в терминале команду:

adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh

Способ C — root

Если у телефона есть root-права, служба Shizuku запускается в один тап прямо из приложения.

Важно: без root службу Shizuku нужно запускать заново после каждой перезагрузки телефона. С root это можно настроить на автозапуск.

Шаг 4. Откройте настройки записи в ProZvonki

В ProZvonki перейдите в Настройки → раздел «Данные» → «Запись разговоров». Там появится блок ShizukiVoiceRecorder со статусом Shizuku. Возможные статусы: «Shizuku не запущен или не установлен», «Нет разрешения Shizuku», «Shizuku готов».

Шаг 5. Выдайте разрешение Shizuku

Если статус «Нет разрешения Shizuku», нажмите кнопку «Выдать разрешение Shizuku» и подтвердите запрос во всплывающем окне Shizuku. Статус должен смениться на «Shizuku готов».

Шаг 6. Включите авто-запись звонков

Когда статус «Shizuku готов», включите переключатель «Авто-запись всех звонков». С этого момента входящие и исходящие разговоры записываются автоматически. Записи привязываются к соответствующим звонкам в журнале и хранятся на устройстве в зашифрованном виде. Под переключателем показывается диагностика последней записи.

Особенности отдельных прошивок

По рекомендациям разработчика Shizuku, на некоторых оболочках нужны дополнительные настройки:

  • MIUI / HyperOS (Xiaomi, Redmi, POCO) — в параметрах разработчика смените «Стиль уведомлений об отладке» на «Android» и включите отдельный пункт «Отладка по USB (Настройки безопасности)».
  • ColorOS / Realme UI (OPPO, Realme, OnePlus) — отключите «Мониторинг разрешений» и включите «Отладка по USB (Настройки безопасности)».
  • Flyme (Meizu) — отключите «Защиту платежей Flyme».
  • Если Shizuku произвольно останавливается — разрешите приложению работу в фоне (снимите ограничения энергосбережения) и отключите режим передачи данных по USB в параметрах разработчика.

Если статус в ProZvonki не меняется на «Shizuku готов», перезапустите службу Shizuku и нажмите «Обновить статус».

FAQ

Частые вопросы о записи через Shizuku

Shizuku — это ваше приложение?

Нет. Shizuku — отдельное стороннее приложение от команды RikkaApps. Мы не являемся его разработчиками и не несём ответственности за его работу. Скачивайте Shizuku только с официальной страницы релизов на GitHub и используйте на свой риск.

Нужен ли root для записи?

Нет. На Android 11 и новее службу Shizuku можно запустить через беспроводную отладку прямо на телефоне — без компьютера и без root. Root — лишь необязательная альтернатива, которая упрощает запуск.

Нужно ли что-то делать после перезагрузки телефона?

Да. Без root служба Shizuku останавливается при выключении или перезагрузке телефона. После включения запустите Shizuku заново — иначе запись работать не будет.

Какая версия Android нужна?

Android 11 и новее. На более старых версиях запись через Shizuku недоступна — приложение покажет статус «Недоступно: нужен Android 11+».

Где хранятся записи разговоров?

Записи хранятся на самом устройстве в зашифрованном виде и автоматически привязываются к нужным звонкам в журнале. Никуда за пределы телефона они не передаются.

Соблюдение закона о записи разговоров — на ком?

Запись телефонных разговоров регулируется законодательством вашей страны. Использование функции и предупреждение собеседника о записи — на вашей ответственности.
