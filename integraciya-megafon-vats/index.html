Интеграция ProZvonki с Мегафон ВАТС 2.0

ProZvonki связывает Android-звонилку с облачной АТС Мегафон (ВАТС 2.0): подтягивает статусы звонков в журнал, скачивает записи разговоров и позволяет управлять переадресацией — безусловной и по расписанию — прямо из приложения. Подключение по JWT-токену и логину сотрудника, без отдельного сервера.

Как настроить интеграцию →

Подключение по токену и логину

Интеграция настраивается ключом API (JWT-токеном) из веб-кабинета ВАТС и логином сотрудника. В приложении вы указываете токен и полный логин — и получаете доступ к синхронизации, записям и переадресации. Токен хранится на устройстве в зашифрованном виде.

Синхронизация статусов звонков

Приложение запрашивает из ВАТС отчёт по звонкам за выбранный период и подтягивает их в журнал: направление, длительность разговора и ожидания, линия ВАТС, реально пропущенные и состоявшиеся. Так видно итоги вызовов через облачную АТС рядом с остальной историей.

Записи разговоров

Для звонков с записью приложение скачивает аудиофайл разговора прямо из облачной АТС Мегафон. Записи сохраняются на устройстве в зашифрованном виде — их можно прослушать в карточке звонка.

Безусловная переадресация на личный

Дозвон всех рабочих вызовов на личный мобильный сотрудника с ручным включением и выключением. Доступно два режима: только на личный (чистый перевод) и совместно с рабочим устройством — личный звонит вместе с рабочими, с настраиваемой задержкой.

Переадресация по расписанию

Автоматическое включение и выключение дозвона на личный по расписанию недели — например, в нерабочее время вызовы уходят на личный мобильный, а в рабочее остаются на рабочих устройствах. Интервал может переходить через полночь. Переключение работает по точным будильникам и сохраняется после перезагрузки телефона.

Без своего сервера

Приложение обращается к облачной АТС Мегафон напрямую по её API. Промежуточный сервер не нужен, а доступ ограничен вашим токеном. Для API-доступа в кабинете ВАТС обычно нужно добавить IP в белый список.

FAQ

Частые вопросы об интеграции с Мегафон ВАТС 2.0

Что даёт интеграция с Мегафон ВАТС 2.0?

Приложение подтягивает из облачной АТС Мегафон статусы звонков, скачивает записи разговоров и позволяет управлять переадресацией — безусловной и по расписанию — прямо из звонилки.

Как подключается интеграция?

По JWT-токену (ключ API) из веб-кабинета ВАТС и логину сотрудника. Токен хранится на устройстве в зашифрованном виде. Для доступа к API часто требуется добавить IP в белый список в кабинете ВАТС; если у телефона нет постоянного IP — укажите 0.0.0.0/0 (доступ с любого адреса).

Какая переадресация поддерживается?

Безусловная — дозвон всех вызовов на личный мобильный (только на личный либо одновременно с рабочими устройствами с задержкой) и по расписанию — автоматическое включение и выключение по расписанию недели. Условной переадресации (занят / недоступен / не отвечает) у Мегафон ВАТС 2.0 нет — она есть у Билайн ОАТС.

Нужно ли разрешение на точные будильники?

Для переадресации по расписанию — да. Приложение переключает переадресацию по точным будильникам, поэтому на Android 12 и новее нужно выдать разрешение «Точные будильники», а на строгих оболочках — разрешить автозапуск и снять ограничение батареи, иначе расписание сработает неточно. Подробнее — в инструкции по настройке и на странице настройки телефона.

Кому доступна интеграция с ВАТС?

Облачная АТС Мегафон — российский сервис, поэтому раздел доступен пользователям из России. Остальные интеграции и функции приложения доступны всем.
