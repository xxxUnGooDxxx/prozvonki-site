One UI

Настройка Samsung Galaxy

На One UI Samsung переводит редко используемые приложения в «спящий режим» и ограничивает их в фоне — из-за этого пропадают уведомления о звонках, а напоминания опаздывают. Ниже — как исключить ProZvonki из усыпления и, отдельно, как назначить его телефоном по умолчанию (на некоторых Galaxy пункт «Телефон» спрятан не там, где ожидаешь).

Шаг 1. Разрешите фоновую активность

Откройте Настройки → Приложения → ProZvonki → Батарея и выберите «Без ограничений». Так приложение сможет получать звонки и уведомления при выключенном экране.

Шаг 2. Добавьте в «неспящие приложения»

Откройте Настройки → Обслуживание устройства (Батарея) → Ограничения в фоновом режиме → «Приложения, которые не переходят в спящий режим» и добавьте ProZvonki. Заодно убедитесь, что приложения нет в списках «Спящие» и «Глубоко спящие».

Шаг 3. Отключите автоотключение

В настройках батареи (меню ⋮ → Настройки) отключите «Автоотключение неиспользуемых приложений» и «Перевод в спящий режим неиспользуемых приложений». Иначе через несколько дней без запуска система снова усыпит приложение.

Шаг 4. Разрешите точные будильники и уведомления

Откройте Настройки → Приложения → ProZvonki → «Будильники и напоминания» и включите разрешение (Android 12+). Проверьте, что уведомления приложения включены.

Шаг 5. Сделайте приложением для звонков по умолчанию

Откройте Настройки → Приложения → ProZvonki → «Установить по умолчанию» → «Приложение для звонков» и выберите ProZvonki. На части Galaxy пункт «Телефон» отсутствует в общем списке «Приложения по умолчанию» — тогда назначайте именно отсюда, из карточки приложения.

Важно про телефон по умолчанию: если в разделе «Приложения по умолчанию» нет пункта «Телефон», это особенность One UI, а не ошибка. Установить приложение для звонков можно из карточки самого приложения (шаг 5).

FAQ

Частые вопросы — Samsung

Приложение уходит в спящий режим само по себе

Добавьте его в «Приложения, которые не переходят в спящий режим» (шаг 2) и отключите «Автоотключение неиспользуемых приложений» (шаг 3). Эти две настройки решают проблему усыпления на One UI.

В «Приложениях по умолчанию» нет пункта «Телефон»

Так бывает на некоторых Galaxy. Откройте карточку приложения: Настройки → Приложения → ProZvonki → «Установить по умолчанию» → «Приложение для звонков» — и выберите ProZvonki оттуда.

Уведомления приходят с задержкой

Проверьте, что для приложения выбрано «Без ограничений» в разделе Батарея (шаг 1), а также что включены точные будильники (шаг 4). Режим энергосбережения телефона тоже задерживает фоновые задачи — по возможности держите его выключенным.
