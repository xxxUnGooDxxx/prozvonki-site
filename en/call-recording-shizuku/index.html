Call recording via Shizuku

ProZvonki can automatically record phone calls on Android 11 and newer — without root — using the Shizuku app. Recordings are stored on the phone in encrypted form and linked to calls in the journal. Below is the step-by-step setup and important caveats.

Download Shizuku (GitHub) →

Before you start

  • RuStore build only. Call recording is available only in the RuStore build of ProZvonki. The Google Play build does not have this feature — Google Play does not allow recording phone calls.
  • Shizuku is not our app. Shizuku is developed by a third-party team, RikkaApps. We are not the authors of Shizuku and are not responsible for how it works. Download Shizuku only from the official releases page and use it at your own risk.
  • Android 11 or newer is required. On older versions, recording via Shizuku is not available.

Video guide

How to enable call recording via Shizuku

A short video shows the full setup flow: starting Shizuku, granting permission in ProZvonki, and enabling automatic call recording.

Step 1. Install ProZvonki from RuStore

Make sure you have the RuStore build of ProZvonki — it's the one that has the Shizuku call recording section. If the app was installed from Google Play, uninstall it and install from RuStore. Store links are on the home page.

Step 2. Install the Shizuku app

Download and install Shizuku — a separate app that grants other apps elevated privileges without root. Get it from the official releases page: github.com/RikkaApps/Shizuku/releases (package moe.shizuku.privileged.api). Shizuku is also on some app stores — only install it from a trusted source.

Step 3. Start the Shizuku service

Installing Shizuku alone does not turn it on — you need to start its service. This is the official process from the Shizuku developer. Choose the method that fits you.

Method A — wireless debugging (Android 11+, no computer) — recommended

  1. Enable Developer options: Settings → “About phone” and tap “Build number” 7 times until “You are now a developer” appears. On some firmwares the build number is under “Software information” or “Version”.
  2. Open “Developer options”, turn on “USB debugging”, then find and turn on “Wireless debugging”.
  3. In the Shizuku app tap start via wireless debugging — Shizuku will ask you to pair.
  4. In the phone settings open “Wireless debugging → Pair device with pairing code” and enter the pairing code that Shizuku shows in its notification (done once).
  5. Return to Shizuku and finish the start. If it fails, toggle wireless debugging off and on again. If Shizuku shows “Searching for pairing service”, allow the app to run in the background.

Method B — via a computer (ADB)

Suitable for Android 10 and older, or when wireless debugging is unavailable. Download SDK Platform Tools from Google, enable “USB debugging” on the phone, connect it to the PC over USB and approve the debugging prompt. Then run this command in a terminal:

adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh

Method C — root

If the phone is rooted, the Shizuku service starts with a single tap right from the app.

Important: without root, the Shizuku service must be started again after every phone reboot. With root you can set it to start automatically.

Step 4. Open the recording settings in ProZvonki

In ProZvonki go to Settings → the “Data” section → “Call recording”. There you'll see the ShizukiVoiceRecorder block with the Shizuku status. Possible statuses: “Shizuku is not running or not installed”, “No Shizuku permission”, “Shizuku ready”.

Step 5. Grant the Shizuku permission

If the status is “No Shizuku permission”, tap the “Grant Shizuku permission” button and confirm the request in the Shizuku pop-up. The status should change to “Shizuku ready”.

Step 6. Turn on auto-recording

When the status is “Shizuku ready”, turn on the “Auto-record all calls” toggle. From this point, incoming and outgoing conversations are recorded automatically. Recordings are linked to the matching calls in the journal and stored on the device in encrypted form. The diagnostics of the last recording are shown under the toggle.

Notes for specific firmwares

Per the Shizuku developer's recommendations, some skins need extra settings:

  • MIUI / HyperOS (Xiaomi, Redmi, POCO) — in Developer options change the “USB debugging notification style” to “Android” and enable the separate “USB debugging (Security settings)” option.
  • ColorOS / Realme UI (OPPO, Realme, OnePlus) — disable “Permission monitoring” and enable “USB debugging (Security settings)”.
  • Flyme (Meizu) — disable “Flyme payment protection”.
  • If Shizuku stops randomly — allow the app to run in the background (remove battery restrictions) and turn off the USB data transfer mode in Developer options.

If the status in ProZvonki doesn't change to “Shizuku ready”, restart the Shizuku service and tap “Refresh status”.

FAQ

Frequently asked questions about recording via Shizuku

Why is call recording only in the RuStore build?

Google Play forbids apps from recording phone calls, so the Google Play build of ProZvonki does not have this feature. Recording via Shizuku is only in the build downloaded from RuStore.

Is Shizuku your app?

No. Shizuku is a separate third-party app by the RikkaApps team. We are not its developers and are not responsible for how it works. Download Shizuku only from the official GitHub releases page and use it at your own risk.

Do I need root to record?

No. On Android 11 and newer, the Shizuku service can be started via wireless debugging right on the phone — with no computer and no root. Root is only an optional alternative that makes starting easier.

Do I need to do anything after a reboot?

Yes. Without root, the Shizuku service stops when the phone is turned off or rebooted. After it turns on, start Shizuku again — otherwise recording won't work.

Which Android version is required?

Android 11 and newer. On older versions, recording via Shizuku is not available — the app shows the status “Unavailable: Android 11+ required”.

Where are the recordings stored?

Recordings are stored on the device itself in encrypted form and are automatically linked to the matching calls in the journal. They are not sent anywhere off the phone.

Who is responsible for complying with call-recording laws?

Recording phone calls is regulated by the laws of your country. Using the feature and warning the other party about recording is your responsibility.
