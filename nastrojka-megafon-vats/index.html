Инструкция

Как настроить интеграцию с Мегафон ВАТС 2.0

Подключение выполняется по JWT-токену и логину сотрудника и не требует своего сервера: вы получаете токен в веб-кабинете ВАТС, добавляете IP в белый список, вводите токен и логин в ProZvonki и настраиваете переадресацию и синхронизацию. Ниже — пошаговый порядок действий.

Шаг 1. Получите токен и логин в ВАТС

В веб-кабинете ВАТС получите ключ API (JWT-токен) и узнайте полный логин сотрудника — например, admin@vats1323914.cp.megafon.ru. Они понадобятся для подключения.

Шаг 2. Добавьте IP в белый список

Доступ к API ВАТС обычно ограничен по IP. В кабинете ВАТС добавьте нужный IP-адрес в белый список — иначе запросы приложения будут отклоняться (ошибки доступа при синхронизации и переадресации).

Шаг 3. Откройте настройки интеграции в ProZvonki

Перейдите в Настройки → вкладка «Бизнес» → Интеграции → Телефония → Мегафон ВАТС 2.0 и включите интеграцию.

Шаг 4. Введите токен и логин

В настройке токена вставьте ключ API (JWT-токен) и укажите полный логин сотрудника в ВАТС. После сохранения станут доступны переадресация, синхронизация и записи разговоров.

Шаг 5. Настройте переадресацию

Включите безусловную переадресацию — дозвон всех вызовов на личный мобильный: режим «только на личный» (чистый перевод) или «совместно с рабочим устройством» (личный звонит вместе с рабочими, с задержкой). Либо выберите переадресацию по расписанию недели. Условной переадресации у Мегафон ВАТС 2.0 нет.

Шаг 6. Разрешите точные будильники (для расписания)

Переадресация по расписанию переключается по точным будильникам. На Android 12 и новее выдайте разрешение «Точные будильники» — в ProZvonki это раздел «Разрешения → Точные напоминания» (открывает системный экран). Без него система откладывает срабатывание, и расписание может сработать неточно. На строгих оболочках (Xiaomi, Huawei, Honor и др.) дополнительно разрешите автозапуск и снимите ограничение батареи — иначе после перезагрузки расписание не восстановится. Подробнее — настройка телефона по производителям.

Шаг 7. Синхронизируйте статусы и записи

Запросите из ВАТС статусы звонков за выбранный период — итоги вызовов через облачную АТС подтянутся в журнал. Для звонков с записью можно скачать аудиофайл разговора — он сохранится в карточке звонка в зашифрованном виде.

Если раздела нет в настройках

Облачная АТС Мегафон — российский сервис, поэтому подраздел «Телефония» с Мегафон ВАТС показывается пользователям из России. Подразделы «CRM» (Битрикс24, amoCRM) при этом доступны всем.

FAQ

Частые вопросы о настройке

Что нужно для подключения?

Ключ API (JWT-токен) из веб-кабинета ВАТС и полный логин сотрудника. Их вводят в настройке токена. Часто дополнительно нужно добавить IP в белый список доступа к API.

Зачем добавлять IP в белый список?

Доступ к API ВАТС обычно ограничен по IP-адресам. Если IP не в белом списке, сервер отклоняет запросы, и приложение не сможет синхронизировать звонки или менять переадресацию.

Чем отличаются режимы переадресации?

Безусловная переводит все вызовы на личный мобильный: «только на личный» — чистый перевод, «совместно с рабочим устройством» — личный звонит вместе с рабочими с задержкой. По расписанию — включается и выключается автоматически по расписанию недели. Условной переадресации у Мегафон ВАТС 2.0 нет.

Почему расписание срабатывает не вовремя?

Переадресация по расписанию работает через точные будильники. На Android 12+ нужно разрешение «Точные будильники» (в ProZvonki — «Разрешения → Точные напоминания»). На строгих оболочках также разрешите автозапуск и снимите ограничение батареи, иначе система откладывает будильники, а после перезагрузки расписание не восстановится.

Не вижу раздел «Телефония» в настройках

Раздел «Телефония» с Мегафон ВАТС доступен пользователям из России, так как это российский сервис. Разделы «CRM» с Битрикс24 и amoCRM доступны всем.
